Catálogo de Metadatos

Biblioteca de recursos y datos geográficos disponibles. Consulta los metadatos de cada capa y descarga la información en formatos estándar ISO 19115 y Dublin Core.

Selecciona la Capa para Consultar Metadatos

📋 Estándar ISO 19115

El estándar ISO 19115 define el esquema requerido para describir información geográfica y servicios. Proporciona información sobre identificación, extensión, calidad, esquema espacial y temporal, referencia espacial y distribución de datos digitales geográficos.

🏛️ Dublin Core

Dublin Core es un conjunto de quince elementos de metadatos diseñado para describir recursos digitales. Es simple, flexible y ampliamente adoptado para describir recursos web de manera consistente y estructurada.
